1. ¿Qué ocurre cuando ejecutas "node server.js"?
Al ejecutar el comando "node server.js", Node.js interpreta y ejecuta el archivo JavaScript. Este inicia una aplicación web basada en Express que se vincula al puerto 3000 de la máquina local y comienza a escuchar peticiones HTTP entrantes.

2. ¿Qué mensaje aparece en la terminal?
En la terminal aparece el siguiente mensaje:
"Servidor ejecutándose en puerto 3000"

3. ¿Qué sucede cuando visitas la ruta /estado?
Cuando se visita la ruta http://localhost:3000/estado en el navegador o mediante una herramienta como curl, el servidor Express procesa la solicitud GET y responde con un código de estado HTTP 200 OK, enviando un objeto JSON que indica el estado actual del servicio.

Ejemplo de respuesta esperada de /estado:
{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
